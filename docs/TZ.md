# Реестр клеток — техническое задание

## 1. Проблема

Малый бизнес открывается — и его невозможно найти.

1. Сайт в топ поиска не поднять без бюджета на SEO и рекламу. Видно первые пять
   результатов, дальше никто не листает.
2. Google Business Profile требует реальный физический адрес для верификации.
   Абонентский ящик и виртуальный офис запрещены. Люди снимают помещение или
   отмечают собственную квартиру только ради того, чтобы существовать на карте.
3. Бизнесы, оформленные как service-area (выездные, без витрины), не могут
   участвовать в рекламе с промо-меткой на картах Google — для этого нужен
   публично видимый адрес. То есть у кого нет адреса, тот не может даже купить
   себе видимость.
4. Поиск требует, чтобы человек уже знал название или точный запрос. Компания
   «Pro Fix Services», которая чинит ресторанные посудомойки, не будет найдена
   никогда, потому что её название не содержит слов, которые вбивают.

## 2. Идея

Карта города, где место на карте одновременно является рекламным местом.

Это не навигация с прикрученными бизнесами, а витрина бизнесов с прикрученной
навигацией. Пользователь ничего не ищет — он открывает карту и видит, что вокруг
него есть, включая то, о существовании чего не подозревал. Навигация нужна только
как кнопка «как доехать», а для надомных и выездных услуг её нет вообще.

Аналогия: Million Dollar Homepage, только вместо экрана — карта города.

## 3. Ключевые принципы (нарушать нельзя)

1. Обнаружение важнее поиска. Главный экран — карта, а не строка поиска.
2. Одна клетка — одна услуга — один владелец. Занял категорию в клетке —
   конкурент в неё не встанет, пока платишь.
3. Регистрация должна занимать меньше двух минут. Телефон, код, точка, название,
   фото. Никаких документов на входе.
4. Адрес не обязателен. Бизнес без адреса — полноправный участник, а не калека.
5. Владелец должен видеть цифры с первого дня: сколько показов, сколько нажатий
   «позвонить».

## 4. Пользователи

- **Владелец бизнеса.** Хочет, чтобы его существование было заметно. Платит за
  понятный результат: моя услуга, мой район, я тут один.
- **Клиент.** Открывает карту, чтобы понять, что рядом. Часто в срочной ситуации.
  Не знает названий компаний.

## 5. Первый рынок

Майами, Флорида. Рестораны и те, кто их обслуживает: ремонт кухонного
оборудования, холодильное, вентиляция и вытяжки, поставка продуктов, вывоз
отработанного масла, электрика, сантехника, клининг.

Расширение — после того, как этот срез заработает. Не раньше.

## 6. Стек

| Слой | Что берём | Почему |
|---|---|---|
| Карта | MapLibre GL JS | открытый движок, бесплатный, векторный |
| Данные карты | OpenStreetMap | бесплатно |
| Тайлы | MapTiler или Protomaps | бесплатный уровень; Protomaps можно захостить самому |
| Фронт | Next.js (React) | нужен SSR ради индексации карточек в поиске |
| База | PostgreSQL + PostGIS | геозапросы «что в этом квадрате» из коробки |
| ORM | Prisma | |
| Оплата | Stripe (подписки) | |
| Хостинг | Vercel + Neon или Supabase | |

Google Maps Platform не используем — дорого на объёме, условия ограничивают
построение конкурирующего справочника поверх их данных.

## 7. Модель данных

См. `prisma/schema.prisma`. Ключевое ограничение — частичный уникальный индекс
`UNIQUE (cell_id, category_id) WHERE status = 'active'` в таблице `claims`
(`sql/partial_unique_index.sql`). Это и есть правило «одна клетка, одна услуга,
один владелец» — оно живёт в базе, а не в коде.

## 8. Сетка

Клетка привязана к координатам, а не к экрану. Размер по умолчанию 200×200 метров
(сконфигурировано, проверить на кварталах Майами).

```
dLat = size_m / 111320
dLng = dLat / cos(lat в радианах)
cell_y = floor(lat / dLat)
cell_x = floor(lng / dLng)
```

Отрисовка сетки — только при зуме от 15 и выше. Код клетки для человека:
`MIA-<base36(cell_y)><base36(cell_x)>`. Реализация — `src/lib/grid.ts`.

## 9. Слои

- **Слой «Места».** Бизнесы с адресом. Метка привязана к зданию. Работает кнопка
  «Маршрут».
- **Слой «Выезд по району».** Бизнесы без адреса. Вместо точки — зона обслуживания.
  Кнопки только «Позвонить» и «Написать».

Переключение слоёв — один тап, всегда на виду.

## 10. Цены

Тарификация по зонам, зона определяется расстоянием до центра города (даунтаун
Майами).

| Зона | Условие | Цена |
|---|---|---|
| Центр | < 900 м от даунтауна | $40 / мес |
| Средняя | < 2600 м | $20 / мес |
| Край | дальше | $9 / мес |

Цифры черновые, проверить на реальном рынке Майами.

## 11. Верификация

Не подтверждение адреса, а подтверждение существования юрлица.

1. Владелец вводит название компании или регистрационный номер.
2. Система сверяет с открытым реестром (для Флориды — Sunbiz).
3. Совпало и статус активный — галочка «Проверено».
4. Без галочки клетку занять тоже можно, но пользователь видит разницу.

Связка «человек ↔ компания» дожимается оплатой: подписка списывается со счёта
компании. Платёж и есть проверка.

## 12. Экраны

1. **Карта** — главный и единственный вход.
2. **Карточка бизнеса** `/b/slug` — публичная страница, SSR, индексируется
   поисковиками. Заменяет владельцу сайт.
3. **Занять клетку** — тап по клетке → код клетки, зона, цена, категория, название,
   телефон, описание, фото → оплата → штамп.
4. **Кабинет владельца** — статистика по дням: показы, открытия карточки, звонки,
   сообщения.

## 13. Объём первой версии

**Делаем:** карта с сеткой и двумя слоями, регистрация по телефону, занятие клетки
с правилом уникальности категории, публичная карточка с SSR, список «рядом со
мной», бейдж «новый» на 30 дней, счётчик показов и нажатий, оплата через Stripe.

**Не делаем в первой версии:** отзывы и рейтинги, мобильные приложения, чат внутри
сервиса, некоммерческие места города, автоматическую сверку с реестром.

## 14. Порядок запуска

1. Месяцы 1–2. Карта работает, клетки бесплатные. Наполняем Майами вручную.
2. Месяцы 3–4. Гоним трафик, считаем показы.
3. Месяц 5+. Включаем деньги — показываем владельцу его цифры за прошедшее время.

## 15. Метрики

- Сколько бизнесов на карте в Майами.
- Сколько нажатий «позвонить» на один бизнес в неделю.
- Доля владельцев, продливших подписку на второй месяц.
- Сколько заходов на карточки пришло из поиска.
